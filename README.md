# Router Manager: downloads

Router Manager by [Shenzee Tech](https://www.shenzee.lk) lets you see who is on your Wi-Fi, block devices, limit speeds and manage your Dialog 4G router from one simple page.

This repository only hosts the download files. Product details, pricing and license keys are on the website:

- **Windows:** https://www.shenzee.lk/software/router-manager-pc
- **Android:** https://www.shenzee.lk/software/router-manager-android

## Download

Get the latest files from the **[Releases](../../releases/latest)** page:

| Platform | File | Needs |
|---|---|---|
| Windows 10 / 11 (64-bit) | `RouterManager-Setup-1.0.0.exe` | Nothing else. Installs for your user account, no administrator needed. |
| Android 7 or newer | `RouterManager-1.0.0.apk` | Allow your browser to install apps ("Install unknown apps") when Android asks. |

Both are free to try for 14 days. After that a license key from shenzee.lk is needed.

## Windows warning

The Windows installer is not code-signed yet, so Windows SmartScreen may say "Unknown publisher". Choose **More info**, then **Run anyway**. You can check the file is genuine with the SHA-256 checksum shown on each release.

## Supported routers

Full control (block, speed limit, Wi-Fi settings) works with Tozed 4G routers, the kind Dialog supplies. The Windows app can also show who is connected on any router without a password. Android needs a supported router.
